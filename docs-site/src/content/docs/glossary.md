完整表見 repo [`docs/GLOSSARY.md`](https://github.com/sampot/playgrounds/blob/main/docs/GLOSSARY.md)。以下為常用節錄：

| 英文／識別 | 中文 | 說明 |
| --- | --- | --- |
| Playgrounds／場網 | 遊樂場 | **程式識別**名；對外 UI 用「遊樂場」，不是品牌。隸屬 [我是山姆鍋](https://samkuo.me/)。預設場 [play.samkuo.me](https://play.samkuo.me/) |
| 場／場網 | 場／場網 | `*.samkuo.me` 一級子域＝獨立 origin |
| docs.samkuo.me | 文件站 | 「我是山姆鍋」底下遊樂場文件；Starlight；不是場 |
| `/sam/` | 小品型錄 | 開源 SAM 範本清單；預設 [play.samkuo.me/sam/](https://play.samkuo.me/sam/) |
| sandbox | 沙盒 | SAM 實例容器；`sandboxId` |
| SAM | 單頁小程式 | Single-page Application Module |
| 遊樂場介面 | 遊樂場介面 | 外框 UI（舊稱勿對外寫「殼」） |
| 畫布 | 畫布 | iframe 執行結果；`/canvas/…` |
| 總管／Steward | 總管 | 持完整 `env.HOST` 的現行 Agent 角色類名 |
| `.sam` | 沙盒包裹 | 匯入／匯出副檔名 |
| SecretStore | 密鑰庫 | 遊樂場級；每 origin 獨立 |
| 整場重置 | 重置遊樂場 | 清光本 origin 持久化 |
