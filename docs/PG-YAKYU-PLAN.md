# Playgrounds 野球生涯小品（`pg-yakyu`）

> **狀態：** Draft（2026-08-15）— **Phase 0–2 閉環＋Phase 3 手感打磨（無投球）已實作**於本機 `~/dev/sampot/pg-yakyu`；場殼／go KV E2E 與 `listed` 仍待人工驗收  
> **權威決策：** 從屬 [PG-GAMES.md](./PG-GAMES.md) 遊戲交付約束；不另開 DEC  
> **相關：** [playgrounds-host-api.md](./playgrounds-host-api.md)（`/api/kv`）、`.cursor/rules/no-native-dialogs.mdc`、`.cursor/rules/mobile-first-ux.mdc`、[`game-assets/ATTRIBUTION.md`](../game-assets/ATTRIBUTION.md)  
> **程式庫（預定）：** [`sampot/pg-yakyu`](https://github.com/sampot/pg-yakyu) · 本地 `~/dev/sampot/pg-yakyu`

一句話：**虛構青棒校隊＋台味包的生涯小品**——玩家自創打者（可選投手路線），**關鍵打席自己揮棒**，其餘局數快轉模擬；一季短賽程打進紅土全國賽，進度存 KV。

---

## 1. 動機

- 型錄尚無「可自己打的棒球／生涯」；機台向 `pg-hoopshot`／`pg-goalshot` 是連投得分，不是賽局。
- 完整棒球模擬（九人守備、熱血體量）超出 SAM 小品；需鎖 **操作回合＋快轉** 才能上架可玩。
- 台味校隊／甲子園敘事成本低、辨識度高，且不需真實聯盟授權。

---

## 2. 目標

- **可自己打：** MVP 以**打擊時機小遊戲**為主操作；結果進真實壘包／出局／得分狀態機。
- **生涯可完：** 建角 → 例行賽 → 淘汰賽 → 通關或新賽季；單季目標遊玩時間約 **15–30 分鐘**。
- **可攜：** 同一份 HTML/CSS/JS 在場殼與 `go.samkuo.me/s/pg-yakyu` 可玩。
- **可存：** 生涯進度權威在 **`/api/kv`**（禁止裸 `localStorage` 當權威）。
- **手機可玩：** 窄屏單指揮棒；主 CTA 不被次要控件擠掉。

---

## 3. 非目標

- 完整九人守備操作、盜壘小遊戲、雙殺動畫、裁判複審。
- 真實聯盟／球星授權、照片臉模、轉播級 UI；**真實高中／盃賽／隊徽**（見 §4.1 命名邊界）。
- 多人即時對戰／Invite（可列 Phase 4+；非上架門檻）。
- 熱血級養成、自由市場、數百場賽季。
- Build 步驟、`package.json` 依賴、runtime 依賴 `playgrounds/game-assets/` 路徑。

### 4.1 台味包（硬）

世界觀＝**台灣青棒／高中棒球氣氛**的虛構聯賽，不是日本甲子園授權作，也不是中華職棒模擬。玩家感覺應是：紅土、應援、縣市預賽一路打進全國決賽。

#### 命名邊界

| 允許 | 禁止 |
| --- | --- |
| 虛構校名（港都、稻香、山城…） | 真實高中／大學校名、綽號影射可指認者 |
| 虛構盃賽名（例「青砂盃」「紅土全國賽」） | 真實盃賽全名當產品標題（黑豹旗、玉山盃等可作**口吻參考**，勿當正式賽事名） |
| 「甲子園**味**／全國決賽殿堂」當敘事形容 | 甲子園／NPB／MLB／CPBL 商標、隊徽、球星名 |
| 台語／華語棒球口頭禪（陽春砲、三上三下、再見安打） | 需授權的應援歌曲旋律／歌詞 |

#### 玩家所屬

- 預設隊名：**沙盒高中**（可在建角改「本校簡稱」，長度同暱稱限制；仍須是虛構、非真實校）。

- 禁 `alert`／`confirm`／`prompt`；**新開生涯覆寫存檔**屬破壞性 → 頁內確認面（可取消、鍵盤可關）。

## 6. 比賽節奏（關鍵手動）

### 6.1 何時進入打擊操作

玩家角色為**打者**時，下列情況進入手動打擊回合：

1. **輪到玩家打擊**（任何局）。
2. **危機加成（可選開關，預設開）：** 我方落後且 ≥7 局、或滿壘／得分圈兩出局——若下一位是 AI 隊友，仍可快轉；若是玩家則必手動（已含於 1）。
3. **決勝延長：** 若採延長賽簡化（見 §7），玩家打席仍手動。

其餘半局（對手攻擊、隊友打席）→ **`sim.js` 快轉**，推進比分與局數，可顯示一行摘要（「三上三下」「陽春砲」等）。

### 6.2 投手路線（Phase 3）

- 建角選「投手」：**兩用**——攻擊半局手動打擊；防守半局逐打席時機投球（至三出局）。
- 建角選「打者」：僅手動打擊；對手半局快轉（既有行為）。
- 投球判定看 `CTL`／`STA` vs 對手 `power`；成長優先 CTL → STA → ARM。

### 6.3 快轉可控

- 比賽中提供「快轉至下一打席／下半局」（非破壞）。
- 不可跳過**當前已開始的手動打席**。

## 7. 簡化棒球規則

權威實作以狀態機為準；產品對玩家承諾如下。

| 項目 | 規則 |
| --- | --- |
| 局數 | 9 局；平手 → **延長最多 2 局**；仍平 → **突然死亡式再一局**或互射練習賽簡化（實作擇一，測例固定） |
| 出局 | 三出局換攻守 |
| 安打推進 | 一壘安打進一壘（原壘上跑者＋1）；二壘安打＋2；三壘＋3；全壘打清壘計分 |
| 出局種類 | 揮空／接殺／滾地（簡化：不區分雙殺；兩出局前滾地可記「出局＋視情況推進」→ **MVP 滾地＝僅出局不推進**） |
| 保送／觸身 | MVP 可由投球結果表低機率觸發；手動打擊也可用「壞球累計」簡化（見 §8） |
| 暴投／盜壘／犧牲 | **不做** |
| 指定打擊／換投調度 | **不做**（自動） |
| 妨礙／申訴 | **不做** |

計分與勝場判定必須有單元測試（§11）。

## 8. 打擊小遊戲（MVP 核心）

### 8.1 流程

```
選球種（AI 投手）→ 投球軌跡／時間軸前進
  → 玩家在時機窗內點擊／放開「揮棒」
  → 可選：揮棒當下準星左右微調（或固定中央＋時機決定好壞）
  → 判定表 → 更新球數／出局／壘包／得分
```

### 8.2 輸入（mobile-first）

- **主輸入：** 單指點擊或按住鬆開（實作擇一，全遊戲一致）。
- **勿**要求雙指或精確滑鼠軌跡才能得分。
- 可顯示時機條（好球帶中央綠區）；支援 `prefers-reduced-motion` 時縮短投球動畫、保留可讀時機窗。

### 8.3 判定（建議表；實作可調參但測例鎖邊界）

輸入：`timingError`（相對理想點）、`batter.HIT`／`POW`、`pitcher` 球威。

| 區段 | 典型結果 |
| --- | --- |
| 極佳 | 長打／全壘打權重高 |
| 佳 | 一壘安打 |
| 可 | 界外或弱滾（出局） |
| 差 | 揮空；累計兩好球後再差 → 三振 |

球數：MVP 可採 **簡化兩好三壞** 或甚至 **每球即決（無球數）**——**定案：MVP 採「每球即決」**（降低 HUD 複雜度）；Phase 2+ 可加球數。

### 8.4 回饋

- 結果大字＋短音效（有資產才播）。
- 壘包菱形立即更新；得分時比分跳動。

## 9. 生涯模式

### 9.1 建角

| 欄位 | 說明 |
| --- | --- |
| `name` | 暱稱，長度限制（例 1–8 字） |
| `hand` | L／R |
| `path` | `batter`（MVP 唯一實操）／`pitcher`（Phase 3） |
| `stats` | `POW` `HIT` `SPD` `ARM` `CTL` `STA`，整數 **0–99** |

起始：各維度約 **42–55** 隨機小幅；`path` 微調（打者 HIT／POW＋；投手 CTL／STA＋）。

### 9.2 賽季結構

| 階段 | 場數 | 說明 |
| --- | --- | --- |
| 例行賽 | **8** | 對手池 6–8 隊，能力遞增；主客場可忽略 |
| 淘汰賽 | **3**（準決→決→ thr 或 四強→準→決） | 敗一場 → 季終「明年再來」 |
| 通關 | — | 決賽勝 → 獎盃敘事；可開新賽季（能力小幅保留上限） |

戰績：勝－敗；個人累計：打席、安打、HR、打點（簡化：得分圈推進計打點規則寫進測例）。

### 9.3 成長

- 賽後依表現給 **1–3 點**可自動分配（MVP：**自動偏向 HIT／POW**，勿做複雜配點 UI）。
- 單季能力上限成長約 **＋8～12** 總點；硬上限 99。
- 新賽季：繼承能力 × 衰減或 cap（例：超過 70 的部分 ×0.9），避免無限膨脹。

### 9.4 對手

- 資料與命名以 **§4.1 台味包** 為準（`game/data/opponents.js`）。
- 快轉模擬用 `power` vs 我方隊力（玩家能力加權）抽比分期望；手動打席仍由小遊戲決定、可翻盤。
- 開賽對戰卡：顯示對方 `name`＋`cheer`；賽後可回一句對手風味評語（可選）。

## 10. 持久化

### 10.1 KV 鍵（權威）

前綴由 runtime／catalog 隔離；遊戲內使用短鍵：

| key | 值 | 說明 |
| --- | --- | --- |
| `career` | JSON 字串 | 角色、stats、賽程游標、勝敗、seed |
| `records` | JSON 字串 | 生涯累計（跨季） |
| `settings` | JSON 字串 | 音量、危機提示、reduced 偏好覆寫（可選） |

讀寫：

```js
const res = await fetch('/api/kv/career');
const raw = await res.text();
await fetch('/api/kv/career', { method: 'PUT', body: JSON.stringify(career) });
```

### 10.2 Schema（`career` 最小）

```ts
type Career = {
  v: 1;
  player: {
    name: string;
    hand: 'L' | 'R';
    path: 'batter' | 'pitcher';
    stats: Record<'POW' | 'HIT' | 'SPD' | 'ARM' | 'CTL' | 'STA', number>;
  };
  season: number;
  schedule: { opponentId: string; result: 'W' | 'L' | null }[];
  index: number; // 下一場
  teamWins: number;
  teamLosses: number;
  eliminated: boolean;
  champion: boolean;
};
```

- 寫入失敗：頁內 flash，不靜默丟進度。
- 僅允許輕量暫存（例：當前打席 UI）用記憶體；重整後從 KV 恢復至**賽與賽之間**，進行中比賽可重開該場（可接受）。
