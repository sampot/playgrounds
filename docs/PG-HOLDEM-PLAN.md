# Playgrounds 德州撲克（`pg-holdem`）

> **狀態：** Accepted（2026-08-16）— Phase 0–3 可玩並 **listed**；`sampot/pg-holdem` public  
> **權威決策：** 從屬 [PG-GAMES.md](./PG-GAMES.md) 遊戲交付約束；不另開 DEC  
> **相關：** [playgrounds-host-api.md](./playgrounds-host-api.md)（`/api/kv`）、`.cursor/rules/no-native-dialogs.mdc`、`.cursor/rules/mobile-first-ux.mdc`、[`game-assets/ATTRIBUTION.md`](../game-assets/ATTRIBUTION.md)、既有牌戲 `pg-blackjack`／`pg-big2`  
> **程式庫（預定）：** [`sampot/pg-holdem`](https://github.com/sampot/pg-holdem) · 本地 `~/dev/sampot/pg-holdem`

一句話：**六人桌無限制德州撲克對 AI**——虛擬籌碼、短局 Sit & Go（盲注遞增），手機可折／跟／加；純娛樂非博弈。

---

## 1. 動機

- 型錄有 `pg-blackjack`（對莊）、`pg-big2`／`pg-shisan`（出牌牌型），尚無 **公共牌＋底池下注** 的德州體驗。
- Kenney **Playing Cards**、**Casino Audio**、**Boardgame chips** 皆已在 `game-assets/` 就緒，與 21 點同形交付成本低。
- Sit & Go 短局（約 10–20 分鐘）符合 SAM 小品節奏；完整線上真人桌與真實貨幣不在範圍。

---

## 2. 目標

- **規則可玩：** No-Limit Hold'em（NLHE）核心回合：盲注 → 底牌 → 翻／轉／河 → 攤牌；含 **邊池（side pot）** 與平分。
- **對 AI 可完：** 玩家＋最多 5 名 AI（六人桌）；可選單挑（heads-up）練習。
- **手機可操作：** 折／過或跟／加注；加注以 **½ 底池／底池／全下** 為主 CTA，自訂金額為次要。
- **可攜：** 同一份 HTML／CSS／JS 在場殼與 `go.samkuo.me/s/pg-holdem` 可玩。
- **可存：** 銀行籌碼／戰績權威在 **`/api/kv`**（禁止裸 `localStorage` 當權威）。
- **定位清楚：** 遊戲內與 blurb 標明 **純娛樂、虛擬籌碼、非博弈**。

---

## 3. 非目標

- 真實貨幣、儲值、兌換、抽水、抽獎兌獎。
- 完整線上真人多桌、時間銀行、觀戰、主播 HUD。
- 複雜 HUD 賠率計算器當主玩法（可列 Phase 4+ 教學提示）。
- Build 步驟、`package.json` 依賴、runtime 依賴 `playgrounds/game-assets/` 路徑。
- Invite 真人對戰（可列 Phase 4+；非上架門檻）。
- Omaha／短牌／混合遊戲變體。

## 5. 資訊架構與畫面

### 5.1 畫面清單

| 面 | 職責 | 主 CTA（窄屏必見） |
| --- | --- | --- |
| **大廳** | 銀行籌碼、戰績摘要；選 Sit & Go／單挑 | 開打 |
| **牌桌** | 座位弧形、底池、公共牌、行動列 | 折／跟（或過）／加注 |
| **加注面** | 預設額度＋可選滑桿／數字 | 確認加注／取消 |
| **攤牌／結算** | 亮牌、牌型名、邊池分配動畫摘要 | 下一手 或 回大廳（淘汰後） |
| **局終** | Sit & Go 冠軍／名次、銀行 Δ | 再來一局／回大廳 |
| **設定／關於** | 音量、牌型速查、署名、非博弈聲明 | — |

### 5.2 UX 硬約束

- 禁 `alert`／`confirm`／`prompt`；**重置銀行／清戰績**屬破壞性 → 頁內確認（可取消）。
- 「開打」「下一手」非破壞 → **不要**多一層確認。
- Mobile-first：預設單欄；玩家座位固定在螢幕下方；對手座位沿上緣／兩側縮圖。
- 行動鈕 ≥44×44px；加注預設三鈕並排可捲或折行，勿靠 hover。
- Flash／toast 用頁內狀態列（誰加注、誰全下、邊池建立）。

### 5.3 窄屏牌桌佈局（建議）

```
        [AI2]  [AI3]  [AI4]
   [AI1]                  [AI5]
              公共牌
              底池
        [玩家＋行動列]
```

- 對手只顯示：暱稱、籌碼、狀態（跟／加／全下／蓋牌剪影）。
- 僅在攤牌或秀牌時翻開對手底牌。

## 6. 局內節奏

### 6.1 一手流程

```
發盲注（SB／BB）→ 發兩張底牌
  → 翻牌前下注輪
  → 翻牌（3）→ 下注輪
  → 轉牌（1）→ 下注輪
  → 河牌（1）→ 下注輪
  → 攤牌（≥2 人未蓋）→ 比牌＋分配底池／邊池
  → 淘汰籌碼為 0 者 → 若 ≤1 人有籌碼則局終，否則下一手（盲注可能上調）
```

### 6.2 下注輪規則（產品承諾）

| 項目 | 規則 |
| --- | --- |
| 行動順序 | 翻牌前：UTG（BB 左側）起；翻牌後：SB 起（若仍在） |
| 可做動作 | **蓋牌**；**過牌**（無人下注時）；**跟注**；**加注**；**全下** |
| 加注最低 | 至少＝上一次加注增量（標準 NL 最低加注）；不足則只能全下 |
| 結束條件 | 其餘皆蓋 → 最後一人未攤收池；或本輪所有未蓋者已跟齊且輪回至最後加注者之後 |

權威以狀態機＋測例為準；遊戲內「牌型速查」列牌力名稱即可。

### 6.3 Sit & Go 結構（MVP）

| 項 | 定案 |
| --- | --- |
| 人數 | 6（不足位由 AI 補滿；單挑模式＝2） |
| 起始籌碼 | **1500**／人（可調參，測例鎖預設） |
| 盲注 | 開局 **10／20**；每 **8 手**（或每 **90s** 牆鐘——**定案：每 8 手**，避免背景頁暫停爭議）升一級 |
| 盲注表 | 10/20 → 15/30 → 25/50 → 50/100 → 75/150 → 100/200 → 150/300 → 250/500 → … 至合理上限 |
| 結束 | 僅一人仍有籌碼 → 冠軍；其餘記名次（依淘汰順序） |
| 銀行結算 | 報名費固定（例 **500** 從銀行扣）；冠軍＋獎金池、或依名次發虛擬獎勵（見 §10） |

## 7. 規則細節（實作契約）

### 7.1 牌與牌型

一手用 **七選五**（2 底牌＋最多 5 公共牌）取最佳五張。牌型由高到低：

1. 同花順（含皇家同花順，可併入同花順最高）
2. 四條
3. 葫蘆
4. 同花
5. 順子（A-2-3-4-5 為最小順；A 高順至 T-J-Q-K-A）
6. 三條
7. 兩對
8. 一對
9. 高牌

踢腳與平分依標準撲克比較；**必須有單元測試**覆蓋邊界（車輪順、同花踢腳、邊池多贏家）。

### 7.2 邊池（硬）

- 多人全下且籌碼不等 → 建立主池／邊池；未投入該層的玩家不得競奪該池。
- 蓋牌者不參與攤牌競池，但其已投入仍留在池中。
- 實作建議：依「本手投入額」分層；每層獨立比牌分配。

### 7.3 發牌與洗牌

- Fisher–Yates；`seed` 可注入以便測例重現。
- 燒牌：MVP **可不做**實體燒牌（對公平無影響）；若做僅動畫。

## 8. AI（MVP）

### 8.1 目標手感

- 不要完美 GTO；要 **可騙、可讀、偶爾亂**，讓新手局可完且不無聊。
- 每名 AI 一組性格權重：`tight`／`loose`、`passive`／`aggressive`（固定種子角色名即可）。

### 8.2 決策輸入（簡）

- 階段（翻前／翻後）、位置、底池賠率粗估、手牌強度分位（翻前用簡表；翻後用 `handRank`＋聽牌啟發）。
- 輸出：蓋／過／跟／加（½ 底或底）／全下；延遲 400–900ms 再揭示（`prefers-reduced-motion` 縮短）。

### 8.3 非目標（AI）

- 無外掛級記牌／多人共謀。
- 無深度搜尋；CPU 預算保持手機流暢。

## 9. 操作與回饋

### 9.1 行動列（玩家）

| 按鈕 | 行為 |
| --- | --- |
| 蓋牌 | 放棄本手 |
| 過牌／跟注 | 依當前需跟額切換文案與金額 |
| 加注 | 開加注面；預設 **½ 底池／底池／全下** |
| （次要） | 自訂額：整數籌碼；非法額頁內提示 |

鍵盤（桌面增強）：`F` 蓋、`C` 過／跟、`R` 開加注——不取代觸控主路徑。

### 9.2 回饋

- 發牌／跟注／全下短音效（Casino Audio）。
- 攤牌時顯示牌型中文名（例「同花順」「兩對」）。
- 淘汰時座位變暗＋名次小標。

## 10. 持久化

### 10.1 KV 鍵（權威）

| key | 值 | 說明 |
| --- | --- | --- |
| `bank` | 字串數字 | 銀行籌碼；預設例 **5000** |
| `records` | JSON | 局數、冠軍次數、淘汰名次累計、峰値銀行 |
| `settings` | JSON | 靜音、單挑偏好等 |

```js
const res = await fetch('/api/kv/bank');
const raw = await res.text();
await fetch('/api/kv/bank', { method: 'PUT', body: String(bank) });
```

無 KV 環境：記憶體內銀行，重整可重置——與 `pg-blackjack` 同形降級。

### 10.2 報名與獎勵（建議表；測例鎖數字）

| 事件 | 銀行 Δ |
| --- | --- |
| Sit & Go 報名 | −500 |
| 冠軍 | ＋2500 |
| 亞軍 | ＋1000 |
| 季軍 | ＋500 |
| 其餘 | 0（報名費 sunk） |
| 銀行不足報名 | CTA「補至可報名」一次加到 ≥500（或一次補到 5000）；**非**破壞確認 |
| 單挑練習 | 不扣報名；勝負僅 ±練習籌碼（不進銀行）或小幅 ±50（實作擇一，測例固定） |


對齊 `pg-blackjack`：規則純函式＋`app.js` DOM；`npx vitest run`。

### 11.2 必測（TDD）

- `handRank`：各牌型判定＋踢腳＋平分；車輪順；皇家同花。
- `pots`：兩人／三人不等全下邊池；蓋牌後池歸未蓋者。
- `table`：盲注座位、加注最低額、全下後跳過已無籌碼者、一手完整走完。
- `sng`：盲注每 8 手升級；淘汰名次；只剩一人結束。
- AI：給定固定 seed 局面，動作落在合法集合（不測「強」，測「合法」）。

### 11.3 美術／音效

從本機 `game-assets/` **複製**進 repo（勿 runtime 指到 playgrounds 路徑）：

| 用途 | 來源 |
| --- | --- |
| 牌面／牌背 | `art/playing-cards-pack/`（Kenney CC0） |
| 籌碼 | `art/boardgame-pack/` 籌碼圖（Kenney CC0） |
| 音效 | `sfx/casino-audio/`（Kenney CC0） |

**署名硬規則：** 不要求署名也要在 `ATTRIBUTION.md`／遊戲內關於列出。
